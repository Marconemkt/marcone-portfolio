# Portfólio · Marcone Otávio

Site estático de fotografia e filmmaker (coneMaker).

- `index.html`: página principal
- `galeria.html`: galeria por categoria e artista
- `fotos/`, `videos/`, `logos/`: arquivos usados pelo site

Para visualizar localmente: `python3 -m http.server 8000` nesta pasta e abrir http://localhost:8000.
